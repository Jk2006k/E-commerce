# ShopHub – E-Commerce Website

ShopHub is a modern e-commerce web application built with React, TypeScript, Vite, and Tailwind CSS. It provides a simple and smooth shopping experience where users can browse products, manage a cart, and place orders.

---

## Tech Stack

React with TypeScript
Vite for build tooling
Tailwind CSS for styling
Context API for global state
Local Storage for persistence
Supabase support for backend integration

---

## Features

### Product Browsing

Users can explore products across different categories, view product details, and search or filter items easily.

### Shopping Cart

Users can add or remove products, adjust quantities, and see totals update automatically. Cart data is saved in the browser so it remains after refresh.

### Wishlist

Products can be saved for later and accessed anytime. Wishlist items are also stored locally.

### Authentication and Account

The app includes login and registration support along with basic profile and order tracking features.

### Checkout Flow

Users can review their cart, enter shipping details, and complete orders with a clear summary.

---

## Project Structure (Simplified)

src/components – reusable UI components
src/pages – main screens of the app
src/context – global state management
src/data – mock product data
src/types – TypeScript types
